# 第二课：词嵌入与语义理解

## 核心概念

**词嵌入的本质**：
- 将词/句子映射到高维向量空间
- 语义相似的文本在空间中距离近
- 通过大规模文本训练得到

## 关键原理：分布式假设

**"You shall know a word by the company it keeps"**

如果两个词经常出现在相似的上下文中，它们的语义应该相似。

例如：
- "我喜欢吃**苹果**" / "我喜欢吃**香蕉**"
- "**苹果**很甜" / "**香蕉**很甜"

神经网络通过学习这些模式，让"苹果"和"香蕉"的向量接近。

## 实验结果

**实验1：近义词识别**
```
'我喜欢吃苹果' vs '我爱吃苹果':     相似度 0.9808 ✓
'我喜欢吃苹果' vs '我讨厌吃苹果':   相似度 0.5656
```
✅ 词嵌入能识别近义词！

**实验2：同类词识别**
```
'我想吃苹果' vs '我想吃香蕉':   相似度 0.5300
'我想吃苹果' vs '我想吃汽车':   相似度 0.5387
```
⚠️ 句子太短时效果不明显

**实验3：语序理解**
```
'猫咬了狗' vs '狗咬了猫':     相似度 0.9914
'猫咬了狗' vs '猫被狗咬了':   相似度 0.9861
```
✅ 能理解语序，但相似度仍然较高（因为主题相同）

**实验4：跨语言理解**
```
'我喜欢吃苹果' vs 'I like eating apples':  相似度 0.9849 ✓✓✓
'今天天气很好' vs 'I like eating apples':  相似度 0.2240
```
✅✅✅ 多语言模型的魔力！

## 技术演进

**Word2Vec (2013)**
- 每个词一个固定向量
- 无法处理一词多义
- 无法处理未见过的词

**BERT (2018)**
- 上下文相关的词向量
- 同一个词在不同句子中向量不同
- 可以通过子词处理新词

**Sentence Transformers (2019)**
- 直接对整个句子编码
- 专门优化用于语义相似度
- 支持多语言

## 学生思考题回答

**问题1**：为什么"苹果"和"香蕉"相似？
> 学生回答：创建了一个空间坐标系，把词放在空间中，实际意义相同的放在同一块立体空间，当有相同起始坐标指向该区域不同词语时，即使词不相同，但是向量夹角也是比较小的

✅ 理解正确！补充：它们被放在一起是因为训练时经常出现在相似上下文中。

**问题2**：如果训练数据中没有"榴莲"？
> 学生回答：应该是不能

⚠️ 部分正确。Word2Vec不能，但现代模型（BERT）可以通过子词分解处理。

**问题3**：为什么是300-400维？
> 学生回答：这个维的概念和我理解的空间维度有什么关系吗

✅ 就是空间维度！300-400维是经验值：
- 太少（10维）：无法表达复杂语义
- 太多（10000维）：计算慢，容易过拟合
- 300-400维：最佳平衡点

## 跨语言嵌入原理

**问题**：为什么中英文能有0.9849的相似度？

**学生回答**：
> 因为语义是相同，所以相关词语所处在空间中区域相近的，表示向量的夹角余弦值接近1

**评价**：✅ 理解了结果，但还需要理解**如何做到的**。

**深入讲解**：

你说得对，语义相同的句子在向量空间中确实很接近。但关键问题是：**模型怎么知道中文"我喜欢吃苹果"和英文"I like eating apples"语义相同？**

### 多语言模型的训练秘密

**方法1：平行语料训练**
- 使用大量的翻译对（中英文对照）
- 例如：联合国文档、维基百科多语言版本
- 训练目标：让翻译对的向量尽可能接近

**方法2：共享词汇空间**
- 不同语言共享同一个向量空间
- 通过对齐技术，让"苹果"和"apple"的向量接近
- 让"喜欢"和"like"的向量接近

**方法3：跨语言迁移**
- 先在一种语言上训练
- 然后通过对齐矩阵映射到其他语言
- 利用语言之间的结构相似性

### 为什么这很重要？

**实际应用场景**：
1. **跨语言搜索**：用中文查询，能找到英文文档
2. **多语言客服**：一个模型处理多种语言
3. **零样本翻译**：即使没见过某个语言对，也能理解

### 神奇的发现

研究发现，不同语言在语义空间中有**相似的结构**：
- "国王-男人+女人=女王" 在英文中成立
- "King-Man+Woman=Queen" 在中文中也成立
- 这种结构在多语言空间中是对齐的！
